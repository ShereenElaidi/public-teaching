# Public teaching materials

Interactive demos and other materials that are fine to share publicly — nothing private
(notes drafts, exams, grades) belongs in this repository.

| Material | Open |
|---|---|
| MATH 223 · Set 8 · Gram–Schmidt (interactive demo) | [`math223/set08-gram-schmidt/`](math223/set08-gram-schmidt/) |

Every material is a self-contained folder that works offline: open its `index.html` directly, or
serve the repository with any static host (e.g. GitHub Pages — the root `index.html` lists everything).

## Adding a material

1. Put it in its own folder, e.g. `math223/set09-…/`, with an `index.html` that needs no network.
2. Add a row to the table above and a link in the root `index.html`.
